# Security

pstack runs scripts and spawns agents on your machine, so treat it like any code you install.

- **A vulnerability in pstack itself** (skills, playbooks, scripts): report it to the upstream project, [cursor/plugins](https://github.com/cursor/plugins).
- **A problem introduced by this port** (the translation, `tools/`, or the release artifacts): use GitHub's private vulnerability reporting on this repo, under **Security → Report a vulnerability**. Public issues from accounts other than the owner are closed automatically, so a private report is the way to reach the maintainer.
