# pstack-claude

This repo is a Claude port of poteto's pstack, maintained by Claude agents. Read `MAINTAINING.md` in full before any change. It holds the ground rules, the translation spec, and the daily sync runbook.

- `plugin/` is generated by `tools/build.sh`. Never edit it by hand.
- Run `python3 tools/verify.py` (add `--smoke` before landing a sync) and get every check to pass before pushing.
- Only `martin-cousseau`'s issues and pull requests stay open.
